# Sistema de Gestión de Hospedaje
Curso: Diseño de Patrones. Java 21 + Swing (JFrame) + SQL Server + Maven.

## Cómo ejecutar
1. Ejecutar `BD_SqlServer/HotelDB_Script.sql` en SSMS.
2. Copiar `db.properties.example` como `db.properties` y ajustar los datos.
3. Abrir el proyecto en NetBeans, Clean and Build y ejecutar `hotel.Main`.
